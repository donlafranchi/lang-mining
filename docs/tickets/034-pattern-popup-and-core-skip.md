# 034 Pattern popup, finer underline, core words skip

- Tapping a pattern highlight (or its "New to you" chip) opens a popup over the lesson: pattern name as heading, one example, its English, short explanation, Got it, ✕. Closing returns to the same spot. "More examples" opens the patterns page.
- Pattern gets optional short `chunks`; "hace" pattern reworded to "Time since, or how long (hace + time)" with "hace dos años = 2 years ago". Other pattern names not yet reviewed.
- Core-word underline is now fine, dotted and lighter; Settings has a switch to turn it off (cookie, no SQL).
- Core 2,000 page: content words (nouns, verbs, adjectives, adverbs) by default, "Skip to the next 20", "Start at word number", and a switch to include prepositions and other small words.
