# 019 Grammar patterns for any language (Farsi first)

- Pattern catalogs are per language (patterns-es.ts, patterns-fa.ts), ids unique across languages (Farsi ids start fa_), so seen-tracking needs no change. Adding a language means: a catalog file, a line in CATALOGS, and a `patterns` field in its prompt and schema.
- Examples carry optional transliteration; Farsi examples always do.
- Farsi catalog: present perfect, past perfect, progressive (dâram mi-xânam), habitual past, formal future, want/must/can + subjunctive, passive with shodan, ezafe, object marker râ.
- Farsi lessons show New to you cards, paragraph tags and Patterns you know, same as Spanish. The Study > Grammar patterns page has a language switch.
- Farsi examples were written from knowledge and not checked by a native speaker: ask a Persian speaker to skim patterns-fa.ts.
